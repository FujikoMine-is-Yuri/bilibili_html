设置转写方式与 B 站登录状态

首次转写会从 Hugging Face 下载模型到本机（约 150 MB／500 MB），需要联网。下载完成后音频在本机转写，不发送到转写服务；生成网页时文本仍会发送给所选模型。

选择后，音频会上传到 OpenAI 转写服务并使用你的 API 额度。

怎样找到自己的 B 站登录信息？
  1. 在你常用的浏览器打开 bilibili.com 并登录。
  2. 打开开发者工具（Mac Chrome：⌘⌥I），选择 Application／应用。
  3. 在 Cookies 中选择 B 站域名，找到名称为 SESSDATA 的条目，把 Value／值复制到这里。

只读取并保存你主动填写的 B 站登录值，不读取浏览器其他网站的数据。登录值仅发送给 B 站，不发送给 AI；它等同登录凭证，不要发到聊天或分享给他人。配置后也不保证能解除 412 限制。
